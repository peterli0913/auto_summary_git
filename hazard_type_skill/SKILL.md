# 隐患类型判断

在值班报告已经汇总成 Excel 之后使用。输入是那张表，输出还是那张表，只把最后一列「隐患类型」填准。不要改来源、描述、厂区、日期这些列，也不要增删行。

脚本：`classify_hazard_type.py`。只依赖 `openpyxl`。

## 运行

```bash
pip install -r requirements.txt
python classify_hazard_type.py --input "汇总_2026-07-09.xlsx" --output "汇总_2026-07-09_已分类.xlsx"
```

想看每一条为什么判成这一类：

```bash
python classify_hazard_type.py --input "汇总_2026-07-09.xlsx" --output "汇总_2026-07-09_已分类.xlsx" --explain
```

表头必须有「事件描述」。类型列认「隐患类型」或「隐患分类」；两列都没有时，在最后补一列「隐患类型」。

和人工标好的表对一下：

```bash
python classify_hazard_type.py --input "汇总.xlsx" --output "汇总_已分类.xlsx" --check "汇总.xlsx"
```

## 怎么判

先去掉空格和句首编号，再按下面的顺序，命中即停。顺序不能颠倒，否则「静电接地正常」「氮气保护未开启」这种出现在作业描述里的词会判错类。

1. **行为/操作**：刷视频、抽烟、未佩戴、返岗、审批单空白、巡查无记录、物料暴露、拉链没拉。
2. **静电**：没有静电导出、接地卡子没接到扁铁、扁铁起边。只是没贴标签的，不算静电。
3. **高风险操作核查**：正在冲釜、浓缩、卸车、掏料、投料，或者直接排放、静电卡子缺针、氮气流量计看不出、防护和尾气一起被检查。句子里只是提到「投料的氮气管没关」，仍算设备设施。
4. **标识标牌**：缺标识、标签损坏、没有检查标签。句子主体已经是渗漏的，不因为末尾写了「做好标识」就改成标识。
5. **文件记录**：合格签、有效期、仪表过期。
6. **氮气保护**：氮气保护没开、缺氮气或尾气连接。冲釜、checklist 里顺便写到的，已经在第 3 步归到高风险。
7. **气味扩散**：有气味或异味，但没有写渗漏、滴落。
8. **跑冒滴漏（预防）**：单阀、没上锁、缺盲板、阀门没关、视镜里有液。物料还没漏出来。
9. **物料状态**：要入库或暂存。
10. **桶/槽子操作**：打到塑料桶、氨解液进桶。
11. **现场状态**：现场状态差、待清洗件多，而且没有要求当场清理。
12. **设备设施隐患识别**：变形、开口没封、弯折、疏散方向、检测器旁放油漆、阀处于开启、堵门口、快开没改成螺丝。连接处渗漏但处理是紧固的，也归这里。
13. **设备异常**：故障、压力表损坏、漏油、松脱、断裂、报警失效、温度上升。
14. **跑冒滴漏**：渗漏、漏水、滴落、淌水、溢水、污水、垫圈物料痕迹。泵出口析出算泄漏；只是阀门表面析出、让人清理的，算现场5S。结冰后滴冷凝水不算泄漏。
15. **现场5S**：清理、粉尘、锈、保温脱落、地漏、抹布、滤芯乱放。
16. **其他**：正常作业、无风险、反应平稳，以及上面都没罩住的描述。

用示例汇总表里已经填了类型的 150 条描述回放，150 条都会判回原来的类型。表里原先空着的那一条是「阀门未上锁」，会判成跑冒滴漏（预防）。

## 不要做的事

- 不要改事件描述去凑分类。
- 不要另加「置信度」「需人工核对」列。
- 不要用这 16 类以外的名字。示例里没有「化学品暴露」这一列。
